# San Joaquin Valley Town Hall - CSS Assignment (50 Marks)

Complete `c07x_speaker.css` using CSS pseudo-class and pseudo-element selectors.

Required rules:
- `a { font-weight: bold; }`
- `a:link { color: green; }`
- `a:hover, a:focus { color: fuchsia; }`
- `main p:first-child { font-weight: bold; }`
- `main p:first-child::first-letter { font-size: 150%; }`

Do not remove the supplied HTML content.

Run locally: `chmod +x test.sh && ./test.sh`
